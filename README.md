# OTT Streaming Content Trend Analysis

## Project Overview
This project analyzes OTT streaming content using Python, Pandas, Matplotlib, and SQL. It explores content types, genres, release years, countries, streaming platforms, and movie duration.

**Note:** The dataset contains sample practice data and is not official streaming-platform data.

## Objectives
- Compare Movies and TV Shows.
- Identify the top 10 genres.
- Analyze content releases by year.
- Compare average IMDb scores by country.
- Analyze titles by streaming platform.
- Explore average movie duration by year.
